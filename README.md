# D.Youth Worship: Telegram Mini App

Сет-листи, репертуар, тексти й акорди. Дані живуть у Notion, застосунок їх лише читає й пише.

## Хто що бачить
- **Лід** (людина в полі «Лід-вокал» на служінні) і **адміни** (`ADMIN_CHAT_IDS`): бачать і редагують сет-лист, можуть зберегти чернетку й опублікувати.
- **Решта складу** (вказані в полях ролей служіння): бачать склад і опублікований сет-лист лише для перегляду.
- **Ті, кого немає в графіку на найближчі 30 днів**: «Тебе немає в графіку на цей місяць». Репертуар їм доступний.
- Користувача шукають у базі «Люди» за `chat_id`. Якщо його там немає, застосунок скаже про це.

## Тема
Береться з Telegram (`Telegram.WebApp.colorScheme`) і змінюється разом із ним. Поза Telegram працює системна `prefers-color-scheme`.

## Акорди
Поле «Акорди» в базі «Пісні», формат ChordPro: акорд у квадратних дужках перед складом, розділ з `#`.

```
# 1 куплет
[G]В надії ми кожен [D]день,
[Em]І погляд свій підносим [C]вверх.
```
Акорди записують у «Нашій тональності» пісні. Кнопки −/+ в картці транспонують їх.

## Запуск
1. `NOTION_TOKEN`: notion.so/my-integrations → нова інтеграція. На сторінці D.YOUTH WORSHIP: ··· → Connections → додати її.
2. Новий токен бота від @BotFather (старий, що світився в чаті, відкликати: `/revoke`).
3. Vercel: `vercel` у цій папці, потім у Settings → Environment Variables додати `NOTION_TOKEN`, `BOT_TOKEN`, `ADMIN_CHAT_IDS` (див. `.env.example`). `DEV_CHAT_ID` на проді не задавати.
4. У @BotFather: `/mybots` → бот → Bot Settings → Menu Button → вказати URL проєкту Vercel (https). Кнопка меню відкриє застосунок.

## Локально
- `npm test`: перевірка підпису Telegram, розбору тональностей і прав доступу.
- `npm run dev`: перегляд інтерфейсу на вигаданих даних без Notion і Telegram (`http://localhost:3000/?role=lead|member|none`).

## Структура Notion, яку використовує застосунок
- «Служіння»: поля ролей, «Лід-вокал», службові «Сет-лист (чернетка)» і «Сет-лист (опублікований)».
- «Сет-лист»: при публікації застосунок замінює рядки цього служіння, тому історія й лічильники лишаються актуальними.
- «Пісні»: тональності, лінки, «Акорди», текст пісні лежить на самій сторінці.
